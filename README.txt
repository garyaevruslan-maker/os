Ruslan OS working version

Как использовать:
1. Открой index.html в Safari.
2. Если нужны фото, положи файлы сюда:
   assets/portraits/brodsky.jpg
   assets/portraits/dovlatov.jpg
   assets/portraits/tyson.jpg
   assets/portraits/durov.jpg
   assets/portraits/tinkov.jpg
   assets/portraits/galitsky.jpg
3. Заливать на хостинг нужно ПАПКУ ruslan-os-working целиком или ZIP.

Кнопки не перекрываются. Внешних сложных слоев нет.
